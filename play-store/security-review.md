## npm audit 보통 등급 항목

보고된 항목은 Expo CLI와 Android/iOS 네이티브 프로젝트 생성 도구의 전이 의존성에 모여 있습니다. `uuid@7.0.3`은 `xcode@3.0.1`을 통해 설치되며 앱의 성경 읽기 런타임 코드에서 직접 사용하지 않습니다.

npm이 제안한 자동 해결은 Expo 56을 Expo 46으로 바꾸는 호환되지 않는 주요 버전 변경이므로 적용하지 않았습니다. Expo SDK 업데이트에서 수정된 호환 버전이 제공되면 정상적인 SDK 업그레이드 절차로 다시 점검합니다.
