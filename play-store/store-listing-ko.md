# Google Play 기본 스토어 등록정보

## 앱 정보

- 앱 이름: 성경을 읽다
- 기본 언어: 한국어(대한민국)
- 앱 또는 게임: 앱
- 카테고리: 도서 및 참고자료
- 유료 여부: 무료
- 광고 포함: 아니요
- 웹사이트: https://kingchamp3.github.io/bible-reader/
- 개인정보처리방침: https://kingchamp3.github.io/bible-reader/app-privacy.html

## 간단한 설명

여러 번역본으로 성경을 읽고 검색하며 즐겨찾기하는 오프라인 성경 앱

## 자세한 설명

성경을 읽다는 차분한 화면에서 성경 본문을 읽고 찾을 수 있는 오프라인 성경 앱입니다.

개역한글, 개역개정, 공동번역, 현대어성경, NIV, SBLGNT 헬라어 본문을 책과 장별로 탐색할 수 있습니다. 원하는 단어나 문장을 검색하고, 다시 보고 싶은 구절은 즐겨찾기에 보관할 수 있습니다.

주요 기능

- 구약과 신약 66권의 책·장별 탐색
- 여섯 가지 성경 본문 전환
- 번역본 전체 본문 검색
- 구절 즐겨찾기
- 읽던 책과 장 자동 기억
- 글자 크기 조절
- 인터넷 연결 없이 본문 열람

즐겨찾기와 읽기 설정은 사용자의 기기에만 저장되며 계정 가입은 필요하지 않습니다.

## 출시 노트

첫 번째 내부 테스트 버전입니다.

- 오프라인 성경 읽기와 검색
- 번역본 선택
- 즐겨찾기와 읽던 위치 저장
- 글자 크기 조절

## 그래픽 대체 텍스트

- 앱 아이콘: 펼쳐진 성경과 금색 책갈피가 짙은 초록색 배경에 놓인 아이콘
- 기능 그래픽: 펼쳐진 성경과 성경을 읽다 이름이 표시된 초록색 배너

## 제출 전 확인

스토어에 공개하기 전에 포함된 각 성경 번역본의 전자적 복제·배포 권한을 확인하고 증빙을 보관해야 합니다. 권한이 확인되지 않은 번역본은 공개 트랙에서 제외합니다.
