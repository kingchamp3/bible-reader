# Google Play 데이터 보안 답안 초안

이 문서는 현재 네이티브 Android 앱 `1.0.0` 기준입니다. 웹사이트의 Google 로그인과 Firebase 기능은 Android 앱에 포함되어 있지 않습니다.

## 데이터 수집 및 공유

- 앱이 사용자 데이터를 수집하거나 공유하나요?: 아니요
- 처리되는 데이터가 전송 중 암호화되나요?: 해당 없음
- 사용자가 데이터 삭제를 요청할 수 있나요?: 앱 데이터 삭제 또는 앱 제거로 기기 저장 데이터를 직접 삭제할 수 있음
- 앱에서 계정을 만들 수 있나요?: 아니요

## 기기에만 저장되는 정보

- 선택한 번역본, 책, 장
- 글자 크기
- 즐겨찾기한 구절 식별자

위 정보는 앱의 로컬 저장소에만 보관되고 개발자 또는 제3자 서버로 전송되지 않습니다. 사용자는 Android 설정의 앱 저장공간에서 데이터를 삭제하거나 앱을 제거해 모두 지울 수 있습니다.

## SDK 및 권한

- 광고 SDK: 없음
- 분석 SDK: 없음
- Firebase SDK: Android 앱에는 없음
- 위치, 연락처, 사진, 파일, 카메라, 마이크 권한: 요청하지 않음
- 네트워크 사용: 개인정보처리방침 링크를 사용자가 직접 열 때 외부 브라우저가 사용됨

## 변경 시 다시 검토할 항목

Google 로그인, Firebase 동기화, 오류 수집, 분석, 광고, 기부 결제 또는 푸시 알림을 Android 앱에 추가하면 이 답안과 개인정보처리방침을 출시 전에 갱신해야 합니다.
