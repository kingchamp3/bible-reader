성경을 읽다 홈

개인정보처리방침

이 방침은 Google Play에서 배포하는 Android 앱 성경을 읽다에 적용됩니다. 시행일은 2026년 7월 30일입니다.

1. 수집하는 개인정보

Android 앱은 회원가입, 로그인, 광고 또는 이용 분석 기능을 사용하지 않으며 개발자 서버로 개인정보나 기기 데이터를 전송하지 않습니다.

2. 기기에 저장되는 정보

다음 정보는 앱 기능을 위해 사용자의 기기에만 저장됩니다.

  • 마지막으로 선택한 번역본, 책과 장
  • 사용자가 설정한 글자 크기
  • 즐겨찾기한 구절 식별자

개발자는 이 정보에 접근하거나 제3자와 공유하지 않습니다.

3. 보관 및 삭제

기기에 저장된 정보는 사용자가 Android 설정에서 앱 데이터를 삭제하거나 앱을 제거할 때 함께 삭제됩니다. 앱에는 별도의 온라인 계정이 없으므로 계정 삭제 절차는 적용되지 않습니다.

4. 제3자 제공과 외부 서비스

Android 앱에는 광고, 분석 또는 Firebase SDK가 포함되어 있지 않습니다. 사용자가 앱의 개인정보처리방침 링크를 누르면 기기의 기본 웹 브라우저가 이 페이지를 엽니다. 이때 브라우저와 GitHub Pages에는 각 서비스 제공자의 정책이 적용될 수 있습니다.

5. 아동의 개인정보

Android 앱은 어떠한 사용자의 개인정보도 의도적으로 수집하지 않습니다. 개인정보 수집 기능이 추가되는 경우 관련 법령과 Google Play 정책에 맞게 이 방침을 먼저 갱신합니다.

6. 방침 변경

앱 기능 또는 데이터 처리 방식이 변경되면 이 페이지의 내용과 시행일을 갱신합니다. 중요한 변경은 앱 업데이트 설명 또는 이 페이지를 통해 알립니다.

7. 문의

개인정보 관련 문의는 성경을 읽다 문의 페이지에서 접수할 수 있습니다. 공개 문의 글에는 이메일, 전화번호 등 민감한 개인정보를 적지 마세요.
